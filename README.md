# SlotSync Frontend

Frontend Single Page Application (SPA) for the SlotSync Smart Campus Room and Lab Booking System.

## Live Application
- **Production URL**: [https://vite-project-sandy-one.vercel.app](https://vite-project-sandy-one.vercel.app)

## Tech Stack
- React 18
- Vite
- Redux Toolkit
- React Router 6
- Tailwind CSS
- Motion (`motion/react`)
- Recharts
- Lucide React

## Deployment on Vercel
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Environment Variables**: `VITE_API_URL` (points to your deployed backend URL)
